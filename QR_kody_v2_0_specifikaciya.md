# Спецификация утилиты — QR-коды

---

## Паспорт

- **Номер:** № 7 (сквозной по реестру утилит)
- **Название:** QR-коды
- **Версия:** 2.0
- **Категория:** разные
- **Автор идеи:** Оксана Старкова
- **Реализация (вайб-код):** ИИ2-2 (создание), ИИ10 (перевод в офлайн и стандарт), ИИ10-2 (иконка, формат входа, общий разбор таблиц)
- **Дата создания / доработок:** 07.06.2026 (создание) · 08.07.2026 (офлайн + стандарт, 1.1) · 10.08.2026 (доработка, 2.0)
- **Тип:** single-file HTML
- **Приватность:** полностью локально (в сеть ничего не уходит)

## Назначение

Утилита генерирует статические QR-коды по ссылкам: одиночный код по введённой ссылке или пакетная генерация по списку из Excel/CSV. Предназначена для быстрого создания QR-кодов к материалам, статьям, книгам и ссылкам.

## Вход и выход

- **Вход, одиночный режим:** ссылка (текст).
- **Вход, пакетный режим:** файл `.xlsx` / `.xls` / `.csv`, **один лист**, две колонки — первая «Название», вторая «URL». Первая строка — заголовки; если они не похожи на заголовки, считается данными.
- **Выход:** одиночный режим — QR-код с возможностью сохранить; пакетный — ZIP-архив с QR-кодами по отмеченным строкам, имя файла берётся из колонки «Название».

## Функциональность

- Генерация одиночного QR-кода по ссылке.
- Пакетная генерация: загрузка Excel/CSV, предпросмотр списка, отметка нужных строк, сборка архива.
- Формат входа описан **прямо на странице утилиты**, над областью загрузки.
- Под именем файла показывается, что утилита прочитала: «колонка 1 — название, колонка 2 — ссылка · первая строка распознана как заголовки и пропущена» (или «заголовков нет, первая строка взята как данные»).
- Проверка на входе: если ни одно значение второй колонки не похоже на ссылку — внятная ошибка с напоминанием формата, вместо пачки бессмысленных кодов.
- Кнопка «Очистить» в пакетном режиме.

## Технические детали

- Стек: HTML + CSS + JavaScript. Генерация QR — библиотека `qrcode-generator` (Kazuhiko Arase), встроена локально. Упаковка результата — встроенный JSZip.
- **Общий блок разбора таблиц (версия блока 2, 10.08.2026)** — единый код для утилит № 1, № 3, № 4, № 7, побайтово одинаковый во всех четырёх. Умеет: определение разделителя CSV вне кавычек по стабильности числа колонок; склейку многострочных значений в кавычках; экранированные кавычки; снятие BOM; выбор первого листа `.xlsx` по порядку из книги, а не по имени файла; пустые строки листа; inline-строки. Правится в одном месте и раскладывается по всем четырём.
- **Определение колонок — фиксированное, без эвристик.** Первая колонка название, вторая ссылка. Единственное, что определяется, — является ли первая строка шапкой (по вхождению слов «назв», «ссылк», «url», «name», «title», «link» и по тому, что значение не похоже на ссылку). Решение Оксаны от 10.08.2026: не пытаться угадывать все возможные варианты, а прямо написать требуемый формат на утилите.
- Внешних библиотек и CDN нет: ранее использовавшиеся qrcode-generator (jsDelivr), SheetJS (cdnjs) и JSZip (cdnjs) заменены на локально встроенные; SheetJS (уязвимая 0.18.5) удалён; Google Fonts убраны.
- Хранение данных: нет.
- Обращения в сеть: нет. Шрифты системные.
- Браузеры: любые современные.
- Ограничения: QR-коды статические (ведут прямо на ссылку); для пакетного режима — один лист и порядок колонок «название, ссылка».

## Оформление

Соответствует «Стандарту оформления утилит»: кремово-терракотовая палитра, системные шрифты + серифный заголовок (Georgia/Iowan Old Style), номер «№ 07» в правом верхнем углу, двухстрочный футер с версией и ссылками, иконка-искра вшита в base64 (4 размера: 16/32/48/64), версия в имени файла через подчёркивание (`QR_kody_v2_0.html`). Отклонений нет.

## История версий

> Накопительный раздел. Новая финальная версия добавляется сверху; прежние записи не переписываются. В историю попадают только финальные версии — правки промежуточных сборок свёрнуты в запись той версии, которой они завершились.

### Версия 2.0 (10.08.2026, ИИ10-2)

**Добавлено**

- Требуемый формат входа описан **прямо на странице утилиты**, над областью загрузки: один лист, первая колонка «Название», вторая «URL», первая строка — заголовки.
- Строка под именем файла показывает, что утилита прочитала: «колонка 1 — название, колонка 2 — ссылка · первая строка распознана как заголовки и пропущена» (или что заголовков нет).
- Проверка на входе: если ни одно значение второй колонки не похоже на ссылку — внятная ошибка с напоминанием формата, вместо пачки бессмысленных кодов.
- Кнопка «Очистить» в пакетном режиме.
- Иконка-искра, вшитая в base64 (4 размера: 16/32/48/64).

**Изменено**

- Собственный парсер выгрузки заменён на **общий блок разбора таблиц** — единый код для утилит № 1, № 3, № 4, № 7, побайтово одинаковый во всех четырёх. Закрывает пункт «переиспользовать разбор Excel с утилитами № 1 и № 3».
- **Определение колонок стало фиксированным, без эвристик:** первая колонка название, вторая ссылка. Определяется только то, является ли первая строка шапкой.

**Исправлено**

- **Распознавание шапки.** Заголовки сравнивались на точное совпадение со списком слов. Стоило написать «Название материала» или «Ссылка на статью» — совпадения не было, утилита решала, что шапки нет, и гнала строку заголовков в работу как данные: первым QR-кодом получался код на текст «Ссылка на статью». Теперь заголовки ищутся по вхождению.
- **Столкновение колонок.** Если распознавалась только колонка ссылок и она оказывалась первой, колонкой названия назначалась та же первая — и в имя файла шёл URL.
- **Выбор листа `.xlsx`** определялся сортировкой по имени файла — мог разбираться не тот лист. Исправлено в общем блоке разбора.

**Технические примечания**

- В промежуточной сборке 1.2 была сделана эвристика: колонка ссылок определялась по данным, по количеству значений, похожих на URL, с запасным определением шапки по содержимому. **От неё отказались осознанно** (решение Оксаны, 10.08.2026): предсказуемость важнее универсальности, непонятное поведение хуже понятного ограничения. Функция `bestUrlColumn` удалена; `looksLikeUrl` осталась — используется для определения шапки и для проверки на входе.
- Это записано здесь намеренно, чтобы следующая доработка не пошла тем же путём заново.

### Версия 1.1 (08.07.2026, ИИ10)

Первая версия. Перевод в офлайн: убраны Google Fonts, qrcode-generator (jsDelivr), SheetJS и JSZip (cdnjs) заменены на локально встроенные; SheetJS (0.18.5, с уязвимостями) удалён, разбор `.xlsx` — свой офлайн-парсер; CSV начал реально обрабатываться. Ноль обращений в сеть. Оформление приведено к стандарту, номер исправлен «№ 03» → «№ 07» по реестру.

*Исходная сборка 1.0 (07.06.2026, ИИ2-2): одиночный QR плюс пакетная генерация из Excel, сборка в архив.*
